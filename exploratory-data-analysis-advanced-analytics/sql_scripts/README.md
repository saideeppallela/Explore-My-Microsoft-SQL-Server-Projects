# 📜 SQL Scripts

This folder contains all SQL scripts developed for the **End-to-End Business Analytics with Microsoft SQL Server** project.

The scripts are organized in a logical learning and analysis sequence, covering database exploration, exploratory data analysis (EDA), advanced analytical techniques, and business reporting.

---

## 📂 Script Categories

| Category | Description |
|----------|-------------|
| 🗄️ Database Exploration | Understand the database structure, schemas, and tables. |
| 🔍 Exploratory Data Analysis (EDA) | Analyze dimensions, dates, measures, rankings, and business metrics. |
| 📈 Advanced Analytics | Perform trend analysis, cumulative analysis, performance evaluation, part-to-whole analysis, and customer segmentation. |
| 📊 Business Reports | Generate reusable Customer and Product analytical reports using SQL Server Views. |
